## Publicación automática

1. Crea un repositorio público en GitHub llamado `hola-mundo-github-pages`.
2. Sube el archivo `index.html` a la rama `main`.
3. Abre **Settings > Pages** del repositorio.
4. En **Build and deployment > Source** selecciona **Deploy from a branch**.
5. En **Branch** selecciona `main`, carpeta `/(root)` y pulsa **Save**.
6. Espera a que termine la publicación y visita:
   https://dannypena1026.github.io/hola-mundo-github-pages/

Cada vez que se suba un cambio a la rama `main`, GitHub Pages volverá a publicar el sitio automáticamente.
